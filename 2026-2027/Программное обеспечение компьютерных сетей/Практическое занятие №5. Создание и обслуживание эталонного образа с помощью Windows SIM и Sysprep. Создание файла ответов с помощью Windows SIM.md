## 1. Цель работы

Освоить создание файла ответов (`unattend.xml`) с помощью Windows System Image Manager (Windows SIM), изучить назначение и порядок применения утилиты Sysprep для обобщения эталонного образа Windows 10, а также получить навыки захвата подготовленного образа с помощью DISM в среде виртуализации QEMU/KVM (libvirt) на хостовой машине с ОС «Альт Образование».

## 2. Оборудование и программное обеспечение

- Хостовая машина с ОС **«Альт Образование»**
- Гипервизор **QEMU/KVM** с графическим интерфейсом **virt-manager**
- Виртуальная машина с **Windows 10**
- Установленный в гостевой ОС **Windows ADK** с компонентом **Deployment Tools** (включает Windows SIM и DISM)
- ISO-образ Windows 10 (для доступа к файлу `install.wim`)
- Загрузочный ISO-образ **WinPE** (созданный на занятии №4) или установочный ISO Windows 10 для загрузки в среду восстановления
- Дополнительный виртуальный диск (или подключённый ISO) для сохранения захваченного WIM-образа

## 3. Краткие теоретические сведения

**Файл ответов (answer file)** — это XML-файл, содержащий настройки, которые автоматически применяются на различных этапах установки и настройки Windows. Файл ответов позволяет автоматизировать установку, пропускать этапы OOBE (Out-of-Box Experience), настраивать учётные записи, язык, часовой пояс и другие параметры без участия пользователя. Файл имеет стандартное имя `unattend.xml` (или `Autounattend.xml` при размещении в корне съёмного носителя) и может быть создан вручную в текстовом редакторе, однако Windows SIM делает этот процесс наглядным и защищает от синтаксических ошибок .

**Секции файла ответов:** файл организован в две основные секции — **Components** (компоненты и их параметры, сгруппированные по этапам установки) и **Packages** (пакеты обновлений и языковых средств). Секция Components делится на **этапы конфигурации (configuration passes)** :

| Этап                       | Назначение                                                                                                      |
| -------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `windowsPE`                | Настройки, используемые программой установки Windows                                                            |
| `offlineServicing`         | Обслуживание образа до загрузки ОС                                                                              |
| `generalize`               | Настройки, применяемые при обобщении образа                                                                     |
| `specialize`               | Специфичные для системы настройки (сеть, язык, домен); большинство параметров post-installation находятся здесь |
| `auditSystem`, `auditUser` | Режим аудита                                                                                                    |
| `oobeSystem`               | Настройки, применяемые непосредственно перед появлением окна приветствия Windows                                |

**Windows SIM (Windows System Image Manager)** — утилита из состава Windows ADK, позволяющая создавать и редактировать файлы ответов. Для работы с конкретным образом `install.wim` необходимо сначала создать **файл каталога (.clg)**, который содержит информацию о настройках, применимых к данному образу. Создание каталога может занять несколько минут .

**Sysprep (System Preparation Tool)** — утилита, входящая в состав Windows, которая подготавливает установленную систему к клонированию и развёртыванию. Ключевой режим — **обобщение (`/generalize`)**: Sysprep удаляет уникальные идентификаторы (SID), данные активации и привязки к оборудованию, делая образ универсальным для развёртывания на других машинах. После обобщения система при следующей загрузке проходит этап OOBE, как при чистой установке .

**DISM (Deployment Image Servicing and Management)** — утилита для работы с WIM-образами. С её помощью захватывают подготовленный образ (`/Capture-Image`) и применяют его на целевых машинах (`/Apply-Image`). Захват выполняется **из среды WinPE**, а не из работающей системы, во избежание блокировки файлов .

**Типовой рабочий процесс создания эталонного образа:**

1. Установка и настройка Windows.
2. Создание файла ответов в Windows SIM.
3. Размещение `unattend.xml` в папке `C:\Windows\Panther`.
4. Запуск Sysprep с параметрами `/oobe /generalize /shutdown`.
5. Загрузка из WinPE и захват образа с помощью DISM.

**Особенности работы в QEMU/KVM (libvirt):** для загрузки виртуальной машины с ISO-образа WinPE необходимо подключить его к виртуальному CD/DVD-приводу через virt-manager и изменить порядок загрузки (Boot Options) или воспользоваться меню загрузки (клавиша F12 при старте ВМ в зависимости от прошивки). Дополнительный виртуальный диск для сохранения WIM-образа можно добавить через свойства виртуальной машины (Add Hardware → Storage).

## 4. Порядок выполнения работы

Все действия выполняются **внутри виртуальной машины с Windows 10**, созданной на предыдущем занятии, если не указано иное.

### 4.1. Подготовка среды

1. Убедитесь, что Windows ADK установлен и в меню «Пуск» доступна группа **Windows Kits → Windows ADK**.
2. Подключите ISO-образ Windows 10 к виртуальной машине через virt-manager (если он ещё не подключён).
3. Создайте рабочие папки:

```cmd
mkdir C:\Lab5
mkdir C:\Lab5\AnswerFiles
```

### 4.2. Создание каталога образа в Windows SIM

1. Запустите **Windows System Image Manager** (от имени администратора).
2. В меню выберите **File → Select Windows Image**.
3. Перейдите к файлу `install.wim` на подключённом ISO-образе Windows 10 (путь вида `D:\sources\install.wim`).
4. Выберите редакцию Windows 10 (например, **Windows 10 Pro**) и нажмите **OK**.
5. На запрос о создании файла каталога ответьте **«Да»**. Дождитесь завершения создания `.clg`-файла (может занять несколько минут) .
6. После создания каталога в левой панели **Windows Image** отобразятся доступные компоненты и пакеты.

### 4.3. Создание файла ответов

1. В меню выберите **File → New Answer File**. В правой панели появится пустой файл ответов.
2. Добавьте настройки в соответствующие этапы конфигурации.

#### Задание 1. Настройка параметров OOBE (пропуск экранов приветствия)

1. В панели **Windows Image** разверните **Components → amd64_Microsoft-Windows-Shell-Setup**.
2. Щёлкните правой кнопкой мыши по компоненту и выберите **Add Setting to Pass 7 oobeSystem**.
3. В панели **Answer File** перейдите к **7 oobeSystem → Microsoft-Windows-Shell-Setup → OOBE**.
4. Установите в панели **Properties** следующие значения:
   - `HideEULAPage` = `true`
   - `HideOEMRegistrationScreen` = `true`
   - `HideOnlineAccountScreen` = `true`
   - `HideWirelessSetupInOOBE` = `true`
   - `ProtectYourPC` = `3`

#### Задание 2. Создание локальной учётной записи

1. В панели **Windows Image** разверните **Microsoft-Windows-Shell-Setup → UserAccounts**.
2. Щёлкните правой кнопкой по **LocalAccounts** и выберите **Add Setting to Pass 7 oobeSystem**.
3. В панели **Answer File** разверните **LocalAccounts** и настройте учётную запись:
   - **Username:** `Student`
   - **Group:** `Administrators`
   - **Password:** задайте пароль (например, `P@ssw0rd`)
   - **DisplayName:** `Student`

#### Задание 3. Настройка языка и часового пояса

1. В панели **Windows Image** найдите **Microsoft-Windows-International-Core**.
2. Добавьте компонент в этап **4 specialize**.
3. В панели **Properties** задайте:
   - `InputLocale` = `0409:00000409` (или `0419:00000419` для русской раскладки)
   - `SystemLocale` = `en-US` (или `ru-RU`)
   - `UILanguage` = `en-US` (или `ru-RU`)
   - `UserLocale` = `en-US` (или `ru-RU`)
4. Дополнительно можно добавить **Microsoft-Windows-Shell-Setup** в этап **4 specialize** и задать параметр `TimeZone` = `Russian Standard Time`.

#### Задание 4. Сохранение и проверка файла ответов

1. В меню выберите **Tools → Validate Answer File**. Убедитесь, что в панели **Messages** отсутствуют ошибки (предупреждения допустимы) .
2. Сохраните файл: **File → Save Answer File**, укажите путь `C:\Lab5\AnswerFiles\unattend.xml`.

### 4.4. Размещение файла ответов в системе

1. Скопируйте файл `unattend.xml` в папку, которую Windows автоматически проверяет при загрузке:

```cmd
mkdir C:\Windows\Panther
copy C:\Lab5\AnswerFiles\unattend.xml C:\Windows\Panther\unattend.xml
```

**Пояснение:** папка `C:\Windows\Panther` — стандартное расположение, из которого Windows Setup считывает файл ответов на этапах `specialize` и `oobeSystem`.

### 4.5. Обобщение образа с помощью Sysprep

**Внимание:** перед запуском Sysprep убедитесь, что виртуальная машина не содержит важных данных. Sysprep с параметром `/generalize` необратимо удаляет уникальные идентификаторы системы.

1. Откройте командную строку **от имени администратора**.
2. Перейдите в каталог Sysprep:

```cmd
cd C:\Windows\System32\Sysprep
```

3. Выполните команду обобщения с выключением системы:

```cmd
sysprep.exe /oobe /generalize /shutdown
```

**Пояснение параметров:**
- `/oobe` — при следующей загрузке система перейдёт в режим OOBE;
- `/generalize` — удаляет SID и специфичные для оборудования данные;
- `/shutdown` — выключает компьютер после завершения подготовки .

4. Дождитесь завершения работы Sysprep. Виртуальная машина выключится. **Не включайте её снова с жёсткого диска** — дальнейшие действия выполняются из WinPE.

### 4.6. Захват образа с помощью DISM из WinPE (в среде QEMU/KVM)

1. **Подключите загрузочный ISO-образ WinPE** к виртуальной машине через virt-manager:
   - Откройте свойства виртуальной машины (кнопка с изображением лампочки или **View → Details**).
   - Нажмите **Add Hardware → Storage**.
   - Выберите **Create a disk image for the virtual machine** или **Select or create custom storage** — укажите путь к ISO-файлу `WinPE_amd64.iso`.
   - Device type: **CDROM device**.
   - Нажмите **Finish**.
2. **Добавьте дополнительный виртуальный диск** для сохранения WIM-образа (если ещё не добавлен):
   - **Add Hardware → Storage** → создайте новый виртуальный диск (например, 20 ГБ, формат qcow2).
   - После загрузки в WinPE этот диск потребуется отформатировать в NTFS.
3. **Настройте порядок загрузки**:
   - В свойствах ВМ перейдите в **Boot Options**.
   - Установите флажок **Enable boot menu** и переместите CDROM с WinPE выше жёсткого диска.
   - Либо при старте ВМ нажмите **F12** (если включена опция загрузочного меню) и выберите CDROM.
4. Загрузите виртуальную машину. Откроется командная строка `X:\Windows\System32>`.
5. Определите буквы дисков с помощью `diskpart`:

```cmd
diskpart
list volume
exit
```

Запишите букву тома, на котором установлена Windows (например, `C:` или `D:`), и букву тома для сохранения образа (например, `E:`). **Важно:** в WinPE буквы дисков могут отличаться от тех, что были в работающей Windows.

6. Если дополнительный диск ещё не отформатирован, отформатируйте его:

```cmd
format E: /FS:NTFS /Q
```

7. Выполните захват образа:

```cmd
Dism /Capture-Image /ImageFile:E:\install.wim /CaptureDir:C:\ /Name:"Win10-Lab5-Generalized" /Description:"Эталонный образ после Sysprep"
```

**Пояснение:** `/CaptureDir` указывает корень захватываемого тома (не папку `Windows`, а корень `C:\`). `/ImageFile` — путь к создаваемому WIM-файлу на дополнительном диске .

8. Дождитесь завершения операции. Проверьте, что файл `install.wim` создан:

```cmd
dir E:\install.wim
```

9. Выключите виртуальную машину из WinPE:

```cmd
wpeutil shutdown
```

### 4.7. Проверка результата

1. **Отключите ISO WinPE** от виртуальной машины через virt-manager (удалите CDROM-устройство или очистите путь к образу).
2. **Не загружайте** исходную виртуальную машину с её жёсткого диска — она уже обобщена и при загрузке потребует повторной настройки OOBE.
3. Убедитесь, что созданный `install.wim` доступен. Для проверки можно подключить дополнительный виртуальный диск к другой ВМ или смонтировать его на хосте (если формат диска позволяет).

## 6. Требования к отчёту

1. **Тема и цель работы.**
2. **Скриншоты:**
   - окно Windows SIM с созданным каталогом образа;
   - панель **Answer File** с добавленными компонентами (OOBE, LocalAccounts, International-Core);
   - результат валидации файла ответов (`Tools → Validate Answer File`);
   - содержимое папки `C:\Windows\Panther` с файлом `unattend.xml`;
   - окно выполнения команды `sysprep.exe /oobe /generalize /shutdown` (до выключения);
   - настройки виртуальной машины в virt-manager с подключённым WinPE (CDROM) и дополнительным диском;
   - командная строка WinPE с выполненной командой `Dism /Capture-Image`;
   - результат `dir` с созданным файлом `install.wim` (размер, дата).
3. **Фрагмент файла `unattend.xml`** (ключевые секции: OOBE, LocalAccounts, International-Core).
4. **Выводы:** что освоено, какие трудности возникли (особенно при работе с QEMU/KVM), какие навыки приобретены.

## Приложение. Полезные команды

```cmd
:: Размещение файла ответов
mkdir C:\Windows\Panther
copy C:\Lab5\AnswerFiles\unattend.xml C:\Windows\Panther\unattend.xml

:: Запуск Sysprep с обобщением и выключением
cd C:\Windows\System32\Sysprep
sysprep.exe /oobe /generalize /shutdown

:: Захват образа из WinPE (после определения букв дисков через diskpart)
Dism /Capture-Image /ImageFile:E:\install.wim /CaptureDir:C:\ /Name:"Win10-Generalized"

:: Применение образа на целевой машине (из WinPE)
Dism /Apply-Image /ImageFile:E:\install.wim /Index:1 /ApplyDir:C:\
```

**Важно:** команда `sysprep /generalize` может быть выполнена ограниченное число раз (по умолчанию до 3). Если требуется повторное обобщение после неудачной попытки, может потребоваться правка реестра (`SkipRearm`) или пересоздание виртуальной машины. При возникновении ошибок Sysprep анализируйте файл `C:\Windows\System32\Sysprep\Panther\setuperr.log`.
