## Цель работы

Получить практические навыки установки, настройки и использования анализатора протоколов Wireshark для захвата и анализа сетевого трафика, освоить работу с фильтрами захвата и отображения для поиска пакетов с заданными параметрами.

## Оборудование и программное обеспечение

- Персональный компьютер под управлением Windows 10
- Сетевой адаптер
- Установочный пакет Wireshark (актуальная версия)
- Доступ к локальной сети или интернету

## Краткие теоретические сведения

**Wireshark** — это анализатор сетевых протоколов с открытым исходным кодом, позволяющий перехватывать и анализировать сетевой трафик в реальном времени. Wireshark поддерживает два принципиально разных типа фильтрации:

1. **Фильтры захвата (Capture Filters)** — применяются *до* записи пакетов в буфер. Синтаксис основан на языке BPF (Berkeley Packet Filter). Отбрасывают ненужный трафик, экономя ресурсы системы. Не могут быть изменены во время захвата.

2. **Фильтры отображения (Display Filters)** — применяются *после* захвата, работают с уже записанными пакетами. Не разрушают данные — отфильтрованные пакеты скрываются, но не удаляются, что позволяет экспериментировать без потери информации.

## Порядок выполнения работы

### 1. Установка Wireshark

1. Скачайте установочный пакет.
2. Запустите установщик **от имени администратора** (правой кнопкой мыши → «Запуск от имени администратора»).
3. Проследуйте по шагам мастера установки:
   - Примите лицензионное соглашение;
   - Оставьте компоненты по умолчанию;
   - **Обязательно** установите флажок **«Install Npcap»** — это драйвер, необходимый для захвата пакетов;
   - Рекомендуется установить флажок **«Add Wireshark to the system PATH»** для возможности работы через командную строку.
4. Дождитесь завершения установки и **перезагрузите компьютер** (требуется для корректной работы Npcap).

### 2. Запуск и выбор интерфейса

1. Откройте Wireshark.
2. В главном окне отобразится список доступных сетевых интерфейсов. Определите ваш активный интерфейс:
   - **Ethernet** — проводное подключение;
3. Определить активный интерфейс можно по наличию графика сетевой активности справа от названия.

### 3. Захват трафика

1. Дважды щёлкните по нужному интерфейсу — начнётся захват трафика.
2. В течении 5-10 минут генерируйте сетевую активность: откройте браузер и перейдите на любые сайты, зайдите на сайт 10.4.9.100:8080 в командной строке выполните:
   ```
   ping ya.ru
   ```
3. Остановите захват, нажав **красную кнопку-квадрат** на панели инструментов.

### 4. Анализ захваченного трафика

#### Общая структура окна Wireshark

Захваченные пакеты отображаются в трёх панелях:
- **Верхняя** — список пакетов (номер, время, IP-адреса, протокол, длина, информация);
- **Средняя** — древовидная структура заголовков выбранного пакета (Ethernet, IP, TCP/UDP, прикладной протокол);
- **Нижняя** — шестнадцатеричный дамп содержимого пакета.

#### Задание 1. Анализ структуры пакета HTTP-запроса

1. В фильтре отображения введите `http` и нажмите Enter.
2. Найдите пакет с методом **GET**.
3. Выделите его и изучите структуру по уровням:
   - **Ethernet II** — MAC-адреса источника и назначения;
   - **Internet Protocol (IP)** — IP-адреса источника и назначения;
   - **TCP** — порты источника и назначения (порт 80 — стандартный порт HTTP-сервера);
   - **Hypertext Transfer Protocol** — метод запроса, заголовки, код ответа.
4. Найдите парный пакет-ответ с кодом состояния **200 OK**.

#### Задание 2. Анализ ICMP (ping)

1. Примените фильтр отображения `icmp`.
2. Изучите структуру ICMP-пакетов (Echo Request / Echo Reply).
3. Определите IP-адрес узла, к которому отправлялся ping.

#### Задание 3. Анализ DNS-запросов

1. Примените фильтр `dns`.
2. Найдите запросы типа A (преобразование имени в IP-адрес) и ответы.
3. Выпишите, какие доменные имена запрашивались и какие IP-адреса были получены.

### 5. Работа с фильтрами

#### Фильтры захвата (Capture Filters)

Вводятся в окне **Capture → Options** перед началом захвата. Синтаксис BPF:

| Фильтр                   | Значение                        |
| ------------------------ | ------------------------------- |
| `host 192.168.1.1`       | Только трафик с/на указанный IP |
| `port 80`                | Только трафик на порт 80        |
| `tcp port 443`           | Только TCP-трафик на порт 443   |
| `udp port 53`            | Только DNS-трафик               |
| `icmp`                   | Только ICMP-трафик              |
| `src net 192.168.1.0/24` | Трафик из указанной подсети     |
| `not arp`                | Исключить ARP-трафик            |

#### Фильтры отображения (Display Filters)

Вводятся в строку фильтра в верхней части главного окна. Синтаксис Wireshark:

| Фильтр                            | Значение                                    |
| --------------------------------- | ------------------------------------------- |
| `ip.addr == 192.168.1.1`          | Пакеты с указанным IP (в любом направлении) |
| `ip.src == 192.168.1.10`          | Пакеты только от указанного IP              |
| `ip.dst == 8.8.8.8`               | Пакеты только к указанному IP               |
| `tcp.port == 80`                  | Пакеты TCP с портом 80                      |
| `http.request`                    | Только HTTP-запросы                         |
| `http.response.code == 200`       | HTTP-ответы с кодом 200                     |
| `dns.qry.name contains "example"` | DNS-запросы, содержащие «example»           |
| `frame.len > 1000`                | Пакеты длиной более 1000 байт               |
| `tcp.flags.syn == 1`              | Пакеты с установленным флагом SYN           |

**Логические операторы**:
- `&&` (and) — логическое И;
- `||` (or) — логическое ИЛИ;
- `!` (not) — логическое НЕ.

**Пример составного фильтра:**
```
(http || dns) && ip.addr == 192.168.1.100
```
— отобразить HTTP и DNS-трафик, связанный с хостом 192.168.1.100.
