## Цель работы

Изучить назначение и состав Windows Assessment and Deployment Kit (Windows ADK). Освоить установку Windows 10 на виртуальную машину, установку Windows ADK с компонентом Windows PE, а также создание загрузочного образа среды предустановки (WinPE) с помощью утилит `copype` и `MakeWinPEMedia`.

## Оборудование и программное обеспечение

- Персональный компьютер с установленной ОС (Windows, Linux или macOS) и гипервизором: **Oracle VirtualBox**, **VMware Workstation/Player** или **Hyper-V**
- ISO-образ **Windows 10** (64-bit), например, версии 22H2
- Виртуальная машина с параметрами: 2 CPU, 4 ГБ ОЗУ, 60 ГБ виртуального диска
- Доступ к интернету внутри виртуальной машины
- Установочные файлы **Windows ADK** и **Windows PE add-on** (загружаются с сайта Microsoft)

## Краткие теоретические сведения

**Windows ADK (Assessment and Deployment Kit)** — это набор инструментов от Microsoft, предназначенный для настройки, развёртывания и оценки образов Windows, а также для оценки качества и производительности систем и приложений.

В состав Windows ADK входят следующие ключевые компоненты:

- **Deployment Tools** — набор утилит командной строки, включая **DISM** (Deployment Image Servicing and Management) для монтирования и обслуживания образов, **Sysprep** для подготовки установленной системы к созданию образа, а также **Windows SIM** (Windows System Image Manager) для создания файлов ответов.
- **Windows Preinstallation Environment (Windows PE)** — компактная среда с ограниченным набором служб, используемая для загрузки компьютера без операционной системы, развёртывания образов Windows и восстановления. **Важно:** начиная с версии ADK для Windows 10 1809, Windows PE поставляется **отдельным установочным пакетом** (add-on) и не входит в основной установщик ADK.
- **Windows Assessment Toolkit** и **Windows Performance Toolkit** — средства оценки производительности.
- **USMT** (User State Migration Tool) — средство миграции пользовательских данных.

**WinPE** создаётся на основе рабочего набора файлов, который формируется утилитой `copype`, после чего из него можно создать загрузочный ISO-образ, USB-носитель или виртуальный жёсткий диск с помощью `MakeWinPEMedia`.

## Порядок выполнения работы

### 1. Установка Windows 10 на виртуальную машину

Данный этап является подготовительным — все дальнейшие действия выполняются **внутри** гостевой ОС Windows 10.

1. Создайте новую виртуальную машину в выбранном гипервизоре.
2. Подключите ISO-образ Windows 10 к виртуальному оптическому приводу.
3. Запустите виртуальную машину и выполните стандартную установку Windows 10 (язык, разметка диска, создание учётной записи).
4. Убедитесь, что виртуальная машина имеет доступ в интернет.

### 2. Загрузка установочных файлов Windows ADK

1. Откройте в браузере внутри виртуальной машины страницу загрузки Windows ADK: `https://learn.microsoft.com/windows-hardware/get-started/adk-install`.
2. Скачайте **adksetup.exe** (Windows ADK) — рекомендуется версия **10.1.26100.1 (May 2024)** или более поздняя, совместимая с Windows 10.
3. На той же странице скачайте **adkwinpesetup.exe** (Windows PE add-on для соответствующей версии ADK).

### 3. Установка Windows ADK

1. Запустите `adksetup.exe` **от имени администратора**.
2. На первом экране выберите **«Install the Windows Assessment and Deployment Kit to this computer»** и укажите путь установки (по умолчанию — `C:\Program Files (x86)\Windows Kits\10`).
3. Примите условия лицензионного соглашения и откажитесь от участия в программе улучшения качества (или согласитесь — на результат это не влияет).
4. На экране **«Select the features you want to install»** отметьте:
   - **Deployment Tools** (обязательно);
   - при необходимости — **User State Migration Tool (USMT)**;
   - остальные компоненты можно не устанавливать для экономии места и времени.
5. Нажмите **Install** и дождитесь завершения установки.

### 4. Установка Windows PE add-on

1. Запустите `adkwinpesetup.exe` **от имени администратора**.
2. Выберите **«Install the Windows Preinstallation Environment (Windows PE)»**.
3. Примите лицензионное соглашение и завершите установку.

После установки в меню «Пуск» появится группа **Windows Kits → Windows ADK**, содержащая ярлык **«Среда средств развертывания и работы с образами»** (Deployment and Imaging Tools Environment).

### 5. Создание рабочего набора файлов WinPE с помощью `copype`

1. Запустите **«Среду средств развертывания и работы с образами»** **от имени администратора** (правой кнопкой мыши → «Запуск от имени администратора»).
2. Выполните команду для создания рабочей копии файлов Windows PE для архитектуры amd64:

```cmd
copype amd64 C:\WinPE_amd64
```

**Пояснение:** `copype` создаёт в указанной папке (`C:\WinPE_amd64`) полный набор файлов, необходимый для сборки загрузочного образа WinPE, включая `boot.wim`, файлы загрузки и вспомогательные скрипты. По завершении в консоли отобразится сообщение об успешном создании рабочей копии.

3. Проверьте содержимое папки `C:\WinPE_amd64` — в ней должны находиться подкаталоги `media`, `mount` и файл `winpe.wim` (или `boot.wim` в зависимости от версии).

### 6. Создание загрузочного ISO-образа WinPE с помощью `MakeWinPEMedia`

1. В той же среде выполните команду создания ISO-образа:

```cmd
MakeWinPEMedia /ISO C:\WinPE_amd64 C:\WinPE_amd64\WinPE_amd64.iso
```

**Пояснение:** `MakeWinPEMedia` с ключом `/ISO` создаёт загрузочный ISO-файл на основе рабочего набора, подготовленного утилитой `copype`. Полученный ISO можно использовать для загрузки виртуальных машин, записи на DVD или создания загрузочного USB-носителя.

2. Дождитесь завершения операции. По её окончании в папке `C:\WinPE_amd64` появится файл `WinPE_amd64.iso`.

### 7. Проверка полученного образа

1. Создайте новую виртуальную машину в гипервизоре **без операционной системы**.
2. Подключите созданный ISO-файл `WinPE_amd64.iso` как загрузочный.
3. Запустите виртуальную машину. Должна загрузиться среда WinPE — откроется командная строка с приглашением `X:\Windows\System32>`.
4. Убедитесь, что среда работоспособна, выполнив простую команду, например `ipconfig` или `diskpart` (для выхода из `diskpart` используйте `exit`).
5. Сделайте скриншот загруженной среды WinPE для отчёта.

## Задания для самостоятельного выполнения

### Вариант 1
1. Повторите создание рабочего набора WinPE, но для архитектуры **x86** (если используемая версия ADK поддерживает 32-битный WinPE): `copype x86 C:\WinPE_x86`.
2. Создайте ISO-образ для x86 и проверьте его загрузку в виртуальной машине.
3. Сравните размеры полученных ISO-образов для amd64 и x86. Объясните разницу.

### Вариант 2
1. После создания рабочего набора `C:\WinPE_amd64` смонтируйте образ `winpe.wim` с помощью DISM:

```cmd
Dism /Mount-Image /ImageFile:C:\WinPE_amd64\media\sources\boot.wim /index:1 /MountDir:C:\WinPE_amd64\mount
```

2. Добавьте в смонтированный образ простой текстовый файл `readme.txt` с вашей фамилией.
3. Размонтируйте образ с сохранением изменений:

```cmd
Dism /Unmount-Image /MountDir:C:\WinPE_amd64\mount /Commit
```

4. Создайте ISO-образ заново и убедитесь, что файл `readme.txt` присутствует в загруженной среде WinPE (например, через `dir X:\`).

### Вариант 3
1. Изучите содержимое папки `C:\Program Files (x86)\Windows Kits\10\Assessment and Deployment Kit\Deployment Tools\amd64`.
2. Составьте таблицу из 5–7 ключевых утилит (DISM, OSCDIMG, WSIM и др.), указав их назначение и пример использования.
3. Опишите в отчёте, для чего предназначена каждая утилита и в каких сценариях развёртывания она применяется.

## Требования к отчёту

1. **Тема и цель работы.**
2. **Параметры созданной виртуальной машины** (гипервизор, объём ОЗУ, размер диска, версия Windows 10).
3. **Скриншоты:**
   - окно установки Windows ADK с выбранными компонентами (**Deployment Tools**);
   - окно установки Windows PE add-on;
   - результат выполнения команды `copype amd64 C:\WinPE_amd64`;
   - результат выполнения команды `MakeWinPEMedia /ISO ...`;
   - содержимое папки `C:\WinPE_amd64` с созданным ISO-файлом;
   - загруженная среда WinPE в виртуальной машине (командная строка `X:\Windows\System32>`).
4. **Результаты выполнения индивидуального варианта** (в зависимости от выбранного варианта).
5. **Выводы:** что освоено, какие трудности возникли, какие навыки приобретены.

## Приложение. Полезные команды (выполняются в «Среде средств развертывания и работы с образами» от имени администратора)

```cmd
:: Создание рабочего набора файлов WinPE для amd64
copype amd64 C:\WinPE_amd64

:: Создание загрузочного ISO-образа
MakeWinPEMedia /ISO C:\WinPE_amd64 C:\WinPE_amd64\WinPE_amd64.iso

:: Создание загрузочного USB-носителя (диск P:)
MakeWinPEMedia /UFD C:\WinPE_amd64 P:

:: Монтирование образа boot.wim для внесения изменений
Dism /Mount-Image /ImageFile:C:\WinPE_amd64\media\sources\boot.wim /index:1 /MountDir:C:\WinPE_amd64\mount

:: Размонтирование с сохранением изменений
Dism /Unmount-Image /MountDir:C:\WinPE_amd64\mount /Commit
```

**Важно:** все команды `copype`, `MakeWinPEMedia` и `Dism` должны выполняться **от имени администратора** в среде «Deployment and Imaging Tools Environment». При использовании обычной командной строки без предварительной настройки переменных PATH утилиты могут быть не найдены.
