### Цель работы:
- **Теоретическая:** Изучить принципы работы протокола PVST+ (Per-VLAN Spanning Tree Plus), назначение технологий PortFast и BPDU Guard в коммутируемых сетях с несколькими VLAN и резервными линками.
- **Практическая:** Приобрести навыки настройки PVST+ с явным указанием корневого и вторичных мостов для разных VLAN, распределения VLAN по разным магистральным линкам, а также защиты от сетевых петель с помощью PortFast и BPDU Guard.

---

### Теоретическая справка

**1. Основные термины и определения:**
- **PVST+ (Per-VLAN Spanning Tree Plus)** — протокол Spanning Tree, при котором для каждого VLAN строится отдельное дерево (экземпляр STP). Это позволяет распределять нагрузку между линками и выбирать оптимальные пути для разных VLAN.
- **Rapid PVST+** — улучшенная версия PVST+, обеспечивающая быструю сходимость. В данной работе используется режим `rapid-pvst` как современный вариант PVST+.
- **PortFast** — функция, которая переводит порт коммутатора в состояние Forwarding немедленно, минуя стадии прослушивания и обучения. Применяется только на портах, подключённых к конечным устройствам (ПК, серверы, принтеры).
- **BPDU Guard** — защитный механизм, который отключает порт (переводит в состояние err-disable), если на него поступает BPDU-кадр. Предотвращает подключение несанкционированных коммутаторов и образование петель.
- **Распределение VLAN по линкам** — назначение разных VLAN на разные физические магистральные каналы между коммутаторами. Позволяет балансировать нагрузку и повышать отказоустойчивость.
- **Корневой мост (Root Bridge)** — коммутатор, выбранный в качестве корня дерева STP для данного VLAN. **Вторичный мост (Secondary Root)** — резервный корневой мост, который станет корневым при отказе основного.

**2.2. Базовые принципы:**
- В сети с избыточными линками PVST+ блокирует часть портов, чтобы исключить петли. Для каждого VLAN можно выбрать свой корневой мост, что позволяет использовать разные пути для разных VLAN.
- В данной работе **корневым мостом для всех VLAN назначается SW3**. Коммутаторы SW1 и SW2 становятся вторичными (резервными) корневыми мостами: SW1 — для VLAN 10, SW2 — для VLAN 20. Это обеспечивает отказоустойчивость и предсказуемое распределение трафика.
- PortFast следует включать только на access-портах, подключённых к оконечным устройствам. При включении PortFast порт сразу переходит в Forwarding, что сокращает время подключения.
- BPDU Guard обычно включается на тех же портах, где настроен PortFast. Если на такой порт приходит BPDU (например, подключили другой коммутатор), порт отключается, предотвращая петлю.
- На магистральных портах BPDU Guard не настраивают, так как они должны обмениваться BPDU для работы STP.

**2.3. Команды для настройки:**
- Включение режима Rapid PVST+: `spanning-tree mode rapid-pvst` (или `spanning-tree mode pvst` для классического PVST+).
- Назначение корневого моста: `spanning-tree vlan <vlan-id> root primary` (или `priority`).
- Назначение вторичного корневого моста: `spanning-tree vlan <vlan-id> root secondary`.
- Включение PortFast: `spanning-tree portfast` (в режиме интерфейса).
- Включение BPDU Guard: `spanning-tree bpduguard enable` (в режиме интерфейса).
- Проверка: `show spanning-tree`, `show spanning-tree vlan <id>`, `show spanning-tree interface <int>`, `show interface status`, `show logging`.

### Задание

**1. Обязательная часть**

1. **Построение топологии:**
   - Разместите три коммутатора: SW1, SW2, SW3.
   - Соедините их попарно двумя линками:
     - SW1 ↔ SW2 (2 линка);
     - SW2 ↔ SW3 (2 линка);
     - SW3 ↔ SW1 (2 линка).
   - Подключите оконечные устройства:
     - К SW1: ПК1 (VLAN 10), ПК2 (VLAN 20);
     - К SW2: ПК3 (VLAN 10), ПК4 (VLAN 20);
     - К SW3: Сервер1 (VLAN 10), Сервер2 (VLAN 20).

2. **Настройка VLAN:**
   - На всех коммутаторах создайте VLAN 10 и VLAN 20.
   - Настройте access-порты для конечных устройств в соответствии с их VLAN.

3. **Распределение VLAN по магистральным линкам:**
   - Между SW1 и SW2: первый линк — только VLAN 10, второй — только VLAN 20.
   - Между SW2 и SW3: первый линк — только VLAN 10, второй — только VLAN 20.
   - Между SW3 и SW1: первый линк — только VLAN 10, второй — только VLAN 20.
   - Для этого на каждом магистральном интерфейсе выполните:
     ```
     switchport mode trunk
     switchport trunk allowed vlan <10 или 20>
     ```

4. **Настройка PVST+ (Rapid PVST+) с явным указанием корневых мостов:**
   - Включите режим Rapid PVST+ на всех коммутаторах:
     ```
     spanning-tree mode rapid-pvst
     ```
   - Назначьте **SW3 корневым мостом для всех VLAN** (VLAN 10 и VLAN 20):
     ```
     SW3(config)# spanning-tree vlan 10 root primary
     SW3(config)# spanning-tree vlan 20 root primary
     ```
   - Назначьте **SW1 вторичным корневым мостом для VLAN 10**:
     ```
     SW1(config)# spanning-tree vlan 10 root secondary
     ```
   - Назначьте **SW2 вторичным корневым мостом для VLAN 20**:
     ```
     SW2(config)# spanning-tree vlan 20 root secondary
     ```
   - Проверьте конфигурацию:
     ```
     show spanning-tree vlan 10
     show spanning-tree vlan 20
     show spanning-tree summary
     ```
   - Убедитесь, что SW3 является корневым для обоих VLAN, а SW1 и SW2 — вторичными для соответствующих VLAN.

5. **Настройка PortFast и BPDU Guard:**
   - На всех access-портах коммутаторов включите PortFast:
     ```
     interface <интерфейс>
     spanning-tree portfast
     ```
   - На тех же портах включите BPDU Guard:
     ```
     spanning-tree bpduguard enable
     ```

6. **Тестирование PortFast:**
   - Отключите и снова подключите кабель ПК1 на SW1.
   - Убедитесь, что порт сразу перешёл в состояние Forwarding:
     ```
     show spanning-tree interface <интерфейс>
     ```

7. **Тестирование BPDU Guard:**
   - Подключите дополнительный коммутатор (SW4) к порту с BPDU Guard.
   - Убедитесь, что порт отключился (err-disable):
     ```
     show interface status
     show logging
     ```
   - Восстановите порт:
     ```
     interface <интерфейс>
     shutdown
     no shutdown
     ```

8. **Тестирование отказоустойчивости:**
   - Проверьте связность: с ПК1 (VLAN 10) пингуйте Сервер1 (VLAN 10); с ПК2 (VLAN 20) — Сервер2 (VLAN 20).
   - В режиме симуляции поочерёдно обрывайте магистральные линки и наблюдайте за переключением трафика.
   - Зафиксируйте время восстановления связи.
   - Проверьте распределение VLAN по линкам:
     ```
     show interface trunk
     show spanning-tree vlan 10
     show spanning-tree vlan 20
     ```

**2. Порядок выполнения**
1. Запустите Cisco Packet Tracer, соберите топологию согласно п. 4.1.1.
2. Выполните базовую настройку коммутаторов (имена, отключение неиспользуемых портов).
3. Создайте VLAN и настройте access-порты.
4. Настройте магистральные порты с распределением VLAN.
5. Включите Rapid PVST+, назначьте SW3 корневым для всех VLAN, SW1 — вторичным для VLAN 10, SW2 — вторичным для VLAN 20.
6. Настройте PortFast и BPDU Guard на access-портах.
7. Проведите тестирование согласно пп. 4.1.6–4.1.8.
8. Оформите отчёт.
